# Tutorial 10

Solutions for Tutorial 10 (15-10-2026).

## Python functional programming
- `Question1_StudentMarks.py`: `filter()`, `map()`, `reduce()`, and lambda functions.
- `Question2_SalaryRevision.py`: salary increment and total expenditure.
- `Question3_ProductDiscount.py`: pure function and festival discount.
- `Question4_ElectricityConsumption.py`: filtering, daily costs, total consumption, and pure bill function.

Run a Python program from Terminal with:
```bash
python3 "Question1_StudentMarks.py"
```
Run it from inside the `week 10` folder, or provide the full path to the file.

## Logic programming (Prolog)
- `Question5_CourseEligibility.pl`: prerequisite eligibility.
- `Question6_PromotionEligibility.pl`: employee promotion rule.
- `Question7_ParkingAllocation.pl`: available parking slots by vehicle type.

Open a `.pl` file in a Prolog interpreter such as SWI-Prolog, then run the query shown in the comments at the bottom of the file. The expected results are also documented there.

The Python solutions use only the standard library. The Prolog solutions require a Prolog interpreter to execute.
